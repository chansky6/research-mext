# 《现代数据存储系统中基于机器学习的缓存与分层技术：综述》翻译与总结

> 原文：George Savva, Elena Kakoulli, Herodotos Herodotou. "Machine Learning-Based Caching and Tiering in Modern Data Storage Systems: A Survey." *ACM Computing Surveys*, Vol. 58, No. 11, Article 295, April 2026, 36 pages. DOI: 10.1145/3803857
> 机构：塞浦路斯科技大学（Limassol）、Neapolis University Pafos

---

## 一、摘要（译文）

现代数据存储系统包含多种介质设备（DRAM、NVRAM、SSD、HDD），组织为多级缓存和存储层，以优化性能-成本比。传统的缓存策略（驱逐、准入、预取）和分层策略（放置、迁移）虽然简单，但难以适应现代数据密集型应用中动态复杂的访问模式。因此，基于机器学习（ML）的策略因其预测能力和对缓存/分层操作的主动优化能力而日益流行。ML 技术不仅能提高缓存命中率、降低延迟，还能提供可扩展、高性价比的智能数据放置方案。本综述回顾了最先进的 ML 缓存与分层方法，考察其理论基础与工程实现；给出每类策略最常用的特征、最流行的对比基线和典型评估指标；最后讨论新兴趋势与未来研究方向。

---

## 二、研究背景与动机

- **数据爆炸**：IDC 2024 报告显示全球数据量已达 149 ZB，预计以 21.5% 的年复合增长率增长，2028 年达 394 ZB。
- **系统形态**：现代存储系统已演化为复杂分布式系统，混合了 DRAM、NVRAM、SSD、HDD 等多级缓存与存储层（典型系统如 Tiera、AMC、BAA、OctopusFS、HDFS）。
- **传统策略失效**：LRU、LFU、FIFO、ARC 等启发式策略在大数据分析、HPC、AI 等现代负载下难以应对多样复杂的访问模式。
- **ML 的价值**（论文 Table 1）：更高的缓存命中率（预测准确+动态适应流量模式）、更低延迟、更优的带宽/能耗/资源利用、可扩展性与成本效益。

## 三、综述方法

采用 Kitchenham 系统性文献综述流程：关键词检索 + 雪球抽样 + 信息分析。来源为 IEEE Xplore、ACM DL、SpringerLink、Google Scholar；按引用数与发表渠道影响力筛选，按 ML 技术与缓存/分层应用场景（准入、驱逐、预取、层放置、迁移）分类，再做定性综合与对比分析。

## 四、基础概念（第 4 章要点）

### 4.1 缓存与分层的五个核心策略
| 层面 | 策略 | 作用 |
|---|---|---|
| 缓存 | 准入（Admission） | 决定新读入的数据是否进入缓存 |
| 缓存 | 驱逐（Eviction/Replacement） | 缓存满时决定移除哪些数据 |
| 缓存 | 预取（Prefetching） | 在请求到来前主动加载数据 |
| 分层 | 放置（Placement） | 为新建/新入数据决定初始存储层 |
| 分层 | 迁移（Migration） | 在层间上移（热数据）或下移（冷数据） |

**缓存与分层的本质区别**：分层把数据*移动*到快速存储层，缓存是把数据*复制*到缓存中。

### 4.2 三类 ML 方法
1. **传统 ML**：线性回归、决策树、随机森林、梯度提升树（XGBoost/LightGBM）、SVM 等——依赖人工特征工程，适合结构化数据与中小规模数据集。
2. **强化学习（RL）**：Q-learning、SAC、Double Q-learning 等——通过与环境交互、以奖励信号试错学习，适合动态不确定环境下的序贯决策。
3. **深度学习（DL）**：CNN、RNN/LSTM，以及深度强化学习（DQN 等）——自动从大量数据中学习复杂模式，可处理巨大状态/动作空间。

### 4.3 三种概念架构模型（论文 Figure 2）
1. **离线训练 + 在线推理**：先采集 trace 训练模型再部署；模型稳定、训练成本可控，但对负载漂移适应性差。
2. **增量在线训练 + 在线推理**：运行中持续采集元数据、周期性增量更新模型；能跟上访问模式变化，但引入运行时开销与潜在不稳定。
3. **RL 在线训练 + 在线推理**：Agent 观察状态、执行缓存/分层动作、以命中率/延迟等为奖励，持续更新策略；适应性强但需要精心设计奖励与充分探索。

## 五、ML 缓存策略详解（第 5 章）

### 5.1 缓存驱逐

**传统 ML 方法**：
- **可插拔驱逐框架**（Alluxio，2019）：LRU/LRFU/LIRS/ARC 多策略 + softmax 多分类器在线选择最优策略。
- **Glider**（2019，MICRO）：先用带注意力的 LSTM 离线学习 Belady MIN 最优决策，发现关键只在于少数重要 PC（程序计数器）的存在而非顺序，进而简化为在线 Integer SVM + PC 历史寄存器（PCHR）的轻量方案。
- **LCache**（2021）：决策树预测数据页是否会被再次访问；脏页/干净页分离管理，空闲时把不重访脏页写回闪存转为干净页，配合 Bloom filter 追踪冷热；响应时间最高改善 84%。
- **LHR**（2021）：XGBoost 预测对象未来访问概率，驱逐概率最低者。

**RL 方法**：
- **LeCaR**（2018）：在 LRU 与 LFU 之间维护概率分布，用 regret 最小化在线学习最优组合。
- **TQC**（2018）：Q-learning 按用户请求模式动态调整，命中率比 LRU/LFU/FIFO 提升 8–12%。
- **PARROT**（2020）：模仿学习逼近 Belady 最优策略，基于过去行为与当前状态决策。
- **RLR**（2021，HPCA）：不依赖 PC（避免硬件开销），用 LLC 现成特征训练 RL agent，硬件开销低。

**DL 方法**：
- **Zhong et al.**（2018）：Wolpertinger 架构（actor 网络 + KNN 扩展动作空间 + critic 评估）做内容缓存替换。
- **Catcher+**（2023）：面向云块存储的 DRL 驱逐框架，用阿里云/腾讯云真实 I/O trace 训练，引入优先经验回放加速收敛。

**要点**：最常用特征是 recency、frequency、上次访问时间、内容流行度；最常用基线是 LRU（10 篇）、LFU（6 篇）；主流指标是命中率与延迟。

### 5.2 缓存准入

**传统 ML 方法**：
- **腾讯照片缓存**（2018）：决策树预测"仅访问一次"的照片不予缓存，减少写负载，配合历史表纠错，模型每日更新。
- **Flashield**（2019）：DRAM 作首道过滤，SVM 评估对象"flashiness"（未来被多次读且不修改的可能性），只把高分对象写入 SSD，降低写放大、延长 SSD 寿命。
- **ML-WP**（2020）：对比朴素贝叶斯/逻辑回归/决策树/AdaBoost/随机森林后选用朴素贝叶斯，将数据分为 write-only 与 write-read，仅后者进入 SSD 缓存。

**DL 方法**：
- **Hyper-DQN**（2019）：面向层级 CDN 的多智能体 DRL，集中训练、分布式执行，预测缓存特定内容的效用。
- **DQN 边缘缓存卸载**（2023）：移动边缘计算中联合优化缓存与任务卸载，动态调整准入参数以最小化延迟。

**要点**：大小、频率、recency 是最常用准入特征；Belady 出现 3 次为最常见基线；模型要么做二值"准不准入"决策，要么预测未来访问概率再决策。

### 5.3 联合驱逐与准入

- **AutoCache**（2019，HDFS）：轻量 XGBoost 同时驱动准入（预测文件近期是否被访问）与驱逐（预测哪些文件将变冷），增量重训练适应负载变化，开销极小。
- **Q-caching**（2015）：把 Q-routing 的 cost-to-go 估计扩展到缓存：驱逐用 WLFU 保高检索成本内容，准入比较期望检索成本。
- **SCDL2**（2020，数据湖）：双 Q-learning agent 架构——准入 Agent（按大小/频率/recency 评估）+ 驱逐 Agent（在 LRU/FIFO 等传统策略间选择）。
- **RLCache**（2019）：off-policy DQN 联合优化准入与驱逐，对象张量化表示，ε-greedy 探索。

### 5.4 缓存预取

**传统 ML**：
- **KML**（2023）：内核态 ML 架构，决策树把负载分类为读随机/读顺序/混合等并映射 readahead 参数；也支持 DNN 优化 NFS rsize。
- **Streaming ML**（2023）：Hoeffding 树对流式请求持续学习，免离线重训，实时适应。

**RL**：
- **Pythia**（2021，MICRO）：硬件预取 RL 框架（SARSA），利用程序上下文 + 系统反馈（内存带宽）做多目标在线学习，可配置无需硬件重设计。
- **RL 预取控制**（2023）：按 IPC 与预取精度等硬件计数器动态调节预取激进度。
- **RL-CoPref**（2024）：多预取器协调控制器，tile coding 离散化状态，动态调整预取开关与深度。

**DL**（预取是 DL 最主导的领域）：
- **DeepCache**（2018）：LSTM Encoder-Decoder 预测对象未来流行度，生成"假请求"注入缓存提升命中率。
- **GRU 文件预取**（2019）：Skip-gram 把文件/目录名嵌入向量，GRU 编码访问序列，在 GlusterFS 中实现。
- **DeepPrefetcher**（2020）：LSTM 聚焦连续 LBA 的差值而非绝对值，准确率 64%（C-miner 48%、顺序基线 41%、ARIMA 37%）。
- **Voyager**（2021，ASPLOS）：层级神经网络，地址拆为页+偏移，注意力嵌入解决偏移混叠，地址与 delta 共存词表处理强制缺失。
- 其他（2024）：SNN 预取器、Twilight 神经预取器（比 Voyager 加速 24.1%，轻量版 T-LITE 权重 <0.8MB、29 周期延迟）、CNN+LSTM 混合模型等。

**要点**：预取是三类缓存策略中最难的——错误决策会污染缓存、浪费带宽；基线最分散（No Prefetcher 出现 5 次，另有 38 种技术各出现一次），说明尚无公认标准方案；主流特征是地址、偏移与地址 delta。

## 六、ML 分层策略详解（第 6 章）

### 6.1 层放置

**传统 ML**：
- **Archivist**（2019）：文件访问 tracer + 三层神经网络（relu + softmax），把文件按存储类型（NVM/SSD/HDD）与访问模式分类放置。
- **OLDP**（2024）：目录级放置策略；k-means 聚类已有目录 + LightGBM 分类新目录，结合 AHP 层次分析法与两轮选择防止热目录压垮快设备节点。

**RL**：
- **CoMoRL**（2023）：面向**分离式（disaggregated）存储**的模型基 RL 放置框架，两层抽象 + 元学习保证配置变化时免重训。（该方向唯一近期工作）

**DL**（放置研究中最主流）：
- **Kleio**（2019）：RNN 页面调度器，捕获长程访问依赖，优化异构内存分配。
- **MLP 分类器**（2021）：滑动窗口采样文件访问特征，MLP 把文件分为热/温/冷，分别放 PCM/SSD/HDD。
- **Sibyl**（2022）：DRL（C51 DQN）在快慢两层混合存储中决策页面放置；决策线程与训练线程分离。
- **PBDQN + SAC**（2023）：数据中心网络放置，优先回放缓冲加速训练，SAC 平衡探索利用。

**要点**：最常用特征是容量、读写偏移、I/O 长度、时间戳、带宽；基线极分散（Hashing 与 Oracle 各 2 次，其余 26 种仅出现一次）；常见指标为延迟、吞吐、加速比。

### 6.2 层迁移

**传统 ML**：
- **HDFS 分层框架**（2019，VLDB）：XGBoost + 增量学习预测文件未来访问概率，在 NVRAM/SSD/HDD 间自动升降数据。
- **数据热度预测**（2019）：Random Forest，先快速信号分组再用分组专属模型按时隙预测。
- **K-SVM**（2022）：K-means 辅助 SVM 决定两层数据块迁移；迁移量平均减少 32×，元数据仅 16 KB。
- **LoADM**（2024）：LightGBM 预测目录热度做负载感知迁移。

**RL**：
- **Zhang et al.**（2022/2024）：TD(λ) 时序差分学习，状态含文件热度/大小/排队时间，动作为上移/保留/下移；后续工作用 MDP + 模糊规则逼近处理科学数据集。

**DL**：
- **AST**（2018）：DNN+SVM+用户排序的堆叠集成，预测数据"温度"，冷数据下沉降本。
- **CNN 文件生命周期预测**（2021）：仅用**文件路径**预测文件最后访问时间，定制损失函数减少低估（避免文件过早归档）；**SLRL**（2022）同样 CNN 估寿命，只在创建时更新，按剩余寿命排序迁移。
- **RLRP**（2022）：DQN + 注意力 LSTM，放置与迁移双 Agent，保障公平性与自适应。
- **Proteus**（2022，SIGMOD）：RNN 混合 OLTP/OLAP 负载的分区访问预测。
- **RLTiering**（2022）：A3C 策略梯度，考虑访问频率与存储成本，为每个文件学最优层。

**要点**：常用特征为访问频率/热度、文件大小、时间戳、带宽；模型通常先预测数据属性（访问概率/热度/寿命）再决定升降；LRU 为最常用基线（5 篇）。

## 七、横向对比与讨论（第 7 章）

### 7.1 各策略与 ML 类型的适配规律
| 策略 | 最适配的 ML 类型 | 原因 |
|---|---|---|
| 驱逐 Eviction | RL + 传统 ML | 需要快速适应变化的负载模式 |
| 准入 Admission | 三类均衡 | 环境与需求多样 |
| 预取 Prefetching | DL 主导 | 任务复杂、错判代价高，LSTM 最流行；RL 仅 3 篇 |
| 放置 Placement | DL 主导 | 数据使用模式多样难预测，CNN/RNN 可跟踪使用规律 |
| 迁移 Migration | DL 主导 + 传统 ML 辅助 | 混合方法（ML+传统技术）渐成趋势 |

### 7.2 三类方法权衡（论文 Table 8 核心内容）
| | 传统 ML | RL | DL |
|---|---|---|---|
| **优势** | 元数据/训练开销低、易实现可解释、优于 LRU 等启发式 | 对动态/未见负载适应性强、KB 级元数据即可显著增益 | 捕获丰富时空相关性、准确率/召回率最高 |
| **劣势** | 对动态负载适应性有限、难建模复杂时空关联、依赖特征工程 | 需持续训练/微调、决策延迟略高、学习过程可能出错 | 模型复杂、需大数据与算力、常只在仿真中评估 |
| **开销** | 极低 | 小（KB 级元数据+中等运行时成本） | 较高（更多计算需求） |
| **典型场景** | 驱逐决策、迁移的访问模式预测 | 动态负载的驱逐、混合存储放置 | 高惩罚复杂任务的预取、分层放置/迁移自动化 |

### 7.3 评估生态
- 34 篇仿真（如 ChampSim）vs 24 篇真实硬件实验；34 篇用真实 trace（多来自 SNIA IOTTA 仓库）vs 27 篇合成负载；44 篇测试了动态负载适应性。
- 基准包括 OLTP、FileBench、Ceph、SPEC CPU、GAP、FIU traces、PARSEC、CloudSuite 等。
- **由于评估环境/负载/指标高度不一致，各研究间无法直接横向比较性能**——这是该领域的一个显著问题。

### 7.4 代表性性能数据
- K-SVM：迁移量平均减少 32×，元数据仅 16 KB；LCache 响应时间最高改善 84%。
- Twilight 神经预取器：比 Voyager 加速 24.1%；轻量版 T-LITE 权重 <0.8 MB。
- DeepPrefetcher：预取准确率 64%（对比 C-miner 48%、ARIMA 37%）。

## 八、新兴趋势（8.1 节）

1. **云与边缘计算**：边缘缓存降低对中心云依赖，ML 联合优化移动边缘计算、缓存与通信；混合云-边缘架构动态分配本地快存与中心慢存。
2. **AI 增强的计算与存储**：RL/DL 预测访问模式动态调整缓存与放置；预测分析决定数据留边缘、本地数据中心还是上云。
3. **安全增强**：加密缓存、安全多方计算、区块链方案；AI 异常检测实时监控访问模式防御威胁。
4. **混合云与多层存储方案**：跨公有云/私有云/本地多层统一管理。
5. **新型硬件语境**：NUMA 感知与分离式存储（Carrefour、LegoOS）带来局部性与放置新问题；云原生产分层（AWS S3 Intelligent-Tiering、Azure Blob）；计算存储设备（SmartSSD）支持原位数据搬运与决策。

## 九、挑战与未来方向（8.2 节，论文 Table 9）

| 挑战 | 现状 | 未来方向 |
|---|---|---|
| **能效** | 频繁 I/O 与数据搬运使能耗成为瓶颈 | 负载感知的能效缓存策略、减少写放大、ML 预测访问局部性、低功耗内存、存算协同优化 |
| **负载可变性** | 静态策略在波动负载下失效 | 流式分析 + RL 的实时自适应、在线学习实现运行时自管理 |
| **多租户** | "吵闹邻居"效应导致性能隔离与公平性问题 | AI 增强的 QoS 预测资源争用并再平衡、可解释 AI 提供透明仲裁 |
| **异构系统** | 设备能力与能耗画像差异大难以协调 | ML 存储控制器协同设计、接口标准化 |
| **可扩展性** | 数据与用户负载持续增长 | 联邦/分布式缓存与协同智能框架 |
| **部署与集成** | 处理成本高、与现有系统集成弱 | 轻量模型、标准接口、回退机制 |
| **安全与隐私** | 多层云环境攻击面扩大 | 加密、隐私保护 AI、主动异常检测、零信任框架 |

部分长期视角参考了 NSF 资助的《Data Storage Research Vision 2025》报告。

## 十、结论（译文要点）

- 缓存与分层管理正从简单启发式**明确转向复杂 ML 技术**。
- **RL 是驱逐策略的关键**（快速适应演化中的访问模式）；**DL 主导预取**（建模复杂时空关系）与**分层放置/迁移**（CNN/RNN/DRL 捕捉数据热度与使用模式的微妙变化）；**准入策略在三类方法间均衡分布**。
- 对上述方法的深入理解，是解决现代存储系统能效、负载可变性、多租户、异构性、可扩展性与安全等挑战的基础。

## 十一、对本研究工作的参考价值（面向 xTier / 异构内存研究）

1. **特征工程清单可直接复用**：recency/frequency/size/上次访问时间/访问间隔/文件创建时间几乎覆盖所有策略的最常用特征（对应论文 Tables 2–7 的系统梳理）。
2. **三分类框架（传统 ML / RL / DL）+ 五策略维度（驱逐/准入/预取/放置/迁移）** 是一个清晰的研究定位坐标系，可用于定位自己工作的空白点（例如：RL 在预取与放置方向的研究稀少；联合多策略优化、真实硬件评估都是显著缺口）。
3. **评估方法学警示**：该领域 34/58 仿真 vs 24 真机、trace 来源与指标高度碎片化，论文明确指出跨研究不可直接比较——新工作若在**真实硬件 + 公开 trace（SNIA IOTTA）+ 统一指标（命中率/延迟/吞吐/开销）**上评估将有明显说服力优势。
4. **开销敏感度分级**：传统 ML 极低开销 → RL KB 级元数据 → DL 计算密集。系统级设计需按决策路径的延迟预算选择模型层级。
