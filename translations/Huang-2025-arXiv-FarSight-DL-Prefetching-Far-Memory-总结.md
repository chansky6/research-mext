# Huang et al. 2025 arXiv — FarSight: Deep-Learning-Driven Prefetching for Far Memory 总结

**层次定位**：远端内存（far memory，RDMA 交换式分层）+ DL 预取；不是 DRAM/CXL 页放置问题，但"语义/地址解耦 + 内核内小模型推理"的路线与 xTier 同族，可直接对照。

## 一句话

把"下一个缺页是哪个"编码为 K=64 的序数词表，用 3K 参数的 RetNet 在页等待远端 I/O 时于同核 CPU 上推理（单次 <600ns），配合 future map 在运行时把序数解析回虚拟地址，比 FastSwap/Hermit 最多快 3.6×/2.6×（p.1 摘要、§4.1）。

## 问题

1. **规则预取失效**：图遍历、指针追逐、树索引等数据中心负载的缺页模式无简单规则可循（§2.2 Insight 1, p.3）。
2. **GPU 推理不可行**：Llama-7B 单 token 约 15ms、连 kernel 启动都近 10µs，而 RDMA 4KB 页读仅 ~2µs——GPU 预测太慢迫使预测更远的未来、更不准（§2.3 Insight 2, p.3）。
3. **准确性/开销/泛化三者互斥**：地址词表 2³⁶ 起步（超 LLM 词表 50K–100K 数量级）；离线训练则模型缺运行时信息；ASLR 使绝对地址跨次运行漂移（§2.3 Insight 3, p.4）。

## 机制

- **语义/地址解耦**：模型只预测"序数"（该页之后第 k 常访问的缺页，k∈[0,K)）；运行时为每页维护 future map（K=64 项、每项 4B = 256B/页），首次实际访问时把真实虚拟地址填入表项（§3.2, p.5–6）。模型输入 = 近 h 次缺页地址与 PC 各 mod K 的序列——mod 有损但靠历史+双通道仍可判别（p.5）。
- **推理隐藏在 I/O 后**：仅在同核处理缺页等待远端数据时做推理；权重+历史+热 future map 共 ~20KB 常驻 L1/L2；RetNet（O(1) 推理延迟）用 AVX512 实现，单次预测 <600ns（§3.3, p.6）。推理后异步发预取、立即让出 CPU。
- **多步前瞻**：look-ahead 距离 s = 通信延迟 95 分位 ÷ 平均缺页间隔；用 RetNet 自回归一次连预测 f 页（§3.4, p.7）。
- **输入编码**：旋转位置编码不从 0 起算，而是让滑窗重叠 token 角度对齐以复用已算上下文（§3.4, p.7）。
- **future map 内存管理**：可按单表（256B）粒度换出到远端 + 根页间接层防碎片；否则 K=64 时元数据占总量 6.25%，本地内存 20% 时吃掉本地 31.25%（§3.3, p.6–7）。
- **训练**：部署时用小样本输入全本地跑一遍，采集全量访问 trace 离线训练（模型仅 2240 参数、2 层、隐维 8，Table 1 p.8）；随机丢弃 10% 访问模拟缺页，同一模型跨不同本地内存配比/网速泛化（§3.5, p.8）。

## 论文自陈的局限 + 我的判断

**自陈**（只引原文）：
- 完全随机或纯规则访问不适用，FarSight 回退到规则/无预取、与现有系统持平（§2.2, p.3）。
- 可能结果超过 K 个时，低频后继被截断；高偏斜图（如 PageRank）中此类预取失败对性能影响不大，但被明确放弃（§3.2, p.6）。
- 无 ML 预取基线可比——现有 ML 预取器全是微架构级、无法在真实 Linux 上运行（§4 p.8）。

**我的判断**：
- "mod K + future map" 是全文真正的贡献：把词表从 2³⁶ 压到 64，本质是用运行时哈希表代替模型记地址。代价是 future map 成为新的元数据问题（论文自己的 6.25%/31.25% 数字），且 mod 冲突下模型学到的是"哈希碰撞的语义"——对 K 个候选足够，但正确性完全依赖 future map 填充时机，首次访问的表项为 null、不预取（冷启动每页首访必 miss）。
- 与 xTier 对照：两者都走"小模型进内核关键路径"，但决策时机不同——xTier 在 PEBS 样本上做放置（miss 后学习），FarSight 在缺页等待时做前瞻预取（miss 前行动）；FarSight 的"推理藏在 I/O 等待里"技巧对任何内核内 ML 决策都适用，比 xTier 的批量迁移路径更显式地解决了延迟预算问题。
- 与 ArtMem 对照：ArtMem 的 RL 只调"迁多少"，页选择仍靠统计；FarSight 证明在语义层（而非统计层）预测可以省掉大词表——两条路线共享同一个假设："重复执行的程序逻辑可学习"。该假设在真实生产负载（JIT、GC、数据依赖分支）上成立到什么程度，论文的 4 个负载全是经典模式化程序，证据偏弱。
