# Yi et al. 2025 ISCA — ArtMem: Adaptive Migration in Reinforcement Learning-Enabled Tiered Memory 总结

**层次定位**：内存分层（DRAM/PM 两层；作者称同样适用于 CXL/NUMA 分层，但实测平台是 DRAM+Optane PM）。

## 一句话

用 Q-learning 在内核里动态调"迁移多少页"和"热度阈值"，以 DRAM 访问占比为奖励，在 8 个内存密集负载、6 种内存配比下平均比七个 SOTA 分层系统快 114%，同时靠奖励惩罚把迁移量压到 MEMTIS 的约 1/10（p.1 摘要、p.9 Figure 7、§6.3.3）。

## 问题

1. **性能随负载分化**：AutoNUMA/TPP/Nimble/MEMTIS/Multi-clock/Tiering-0.8/AutoTiering 各有优势与劣势访问模式（Table 1, p.4）——静态热度阈值和启发式无法覆盖全部访问模式。
2. **快层访问占比下降时不调整**：系统性能与 DRAM 访问占比强相关（§3.2 Figure 3, p.4），但现有方案不以此为目标反馈调整迁移策略。
3. **迁移范围固定**：MEMTIS 按 DRAM 容量定阈值，导致 S1 模式下 15GB 全量迁移（§3.1, p.3）；迁移量要么不足要么过量。

## 机制

- **采样**：每 CPU 一个 `ksampled` 内核线程，PEBS 采样（周期初始 200 个事件一次，每 2ms 处理 ring buffer），开销 ≤3% CPU（§4.4 p.7、§6.4 p.12）。
- **热度表示**：按 2 的指数分 bin 记录页访问次数（2MB 大页为迁移单位）；每 200 万样本做一次 cooling，所有计数减半（§4.3 p.6）。最小热度阈值经验值 16 次访问（§5 p.7）。
- **RL（Q-learning，用户态实现，经 cgroup 伪文件 `memory.hit_ratio_show`/`memory.action_show`/`memory.threshold_show` 与内核交互）**：
  - 状态：DRAM 访问占比分桶，k=10 共 12 个状态（§4.2/§5 p.7）；
  - 动作：两张 Q 表——迁移量（0、16MB…2048MB 共 9 档）和阈值调整（±8、±4、0）（§5 p.7）；
  - 奖励：r = τᵢ − β + λ(τᵢ − τᵢ₋₁)，τ 为快层访问占比，β 取 8–10（Algorithm 1 p.7、§6.3.7 p.11）；
  - 超参：α=e⁻²，γ=e⁻¹，ε=0.3，迁移间隔 10s（§6.3.7 p.11）。
- **页排序**：demote 从快层 inactive 链表尾取、promote 从慢层 active 链表头取；迁移页一律插入快层 active 头（比保守策略激进，避免过早降级抖动）（§4.3 p.6）。
- **初始化**：先用 Liblinear 跑几轮预训练 Q 表；Q-learning 与 SARSA 效果相当（§6.2 p.8、§6.3.5 p.11）。

## 论文自陈的局限 + 我的判断

**自陈**（只引原文）：
- 奖励依赖 perf 采样的访问占比，均匀访问负载初期占比掉到 0%、恢复速度受采样精度限制（§6.2 p.9）。
- Q 表对训练负载有敏感性：25 组交叉组合中 7 组掉超 10%，理想情况需目标负载或相似模式负载训练（§6.3.6 p.11）。
- 延迟型奖励（用 pending 请求数近似）平均比访问占比奖励差 3.4%（§6.3.4 p.11）。

**我的判断**：
- 状态空间只有 12 个、动作 9+5 档，"RL"实质是一张极小 Q 表做反馈控制——工程价值在奖励信号（快层访问占比可廉价采样、与性能强相关）而非学习算法本身；换成 PID/启发式调参未必差很多，但论文未做此对比（消融只拆了 RL/EMA/排序三件，§6.3.1 p.9）。
- 实测在 PM 上、慢层延迟 323ns；CXL 场景（更高延迟、带宽受限、多 expander）下采样占比与性能的相关性是否仍强，论文只用远程 DRAM/PM 做了 152–407ns 的敏感性检验（§6.3.9 p.12），未覆盖 CXL 带宽退化的情况，迁移到 CXL 平台需重验。
- 与 xTier 对照：两者都进内核决策，但 xTier 用 32 特征 MLP 学习排序、决策"哪些页"，ArtMem 的 RL 只决策"迁多少 + 阈值"，页选择仍靠 EMA+LRU 排序——粒度更粗，可能部分解释其对均匀访问负载（Liblinear）的弱项。
